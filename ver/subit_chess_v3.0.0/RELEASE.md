## Що в релізі

- Модульний рушій (`src/engine/`, 12 модулів) + єдиний офлайн HTML у результаті.
- Виправлено головний дефект сили: перспектива оцінки (mover-relative в обох tier,
  `white` — white-positive). До виправлення кожен вузол за чорних оцінювався з
  протилежним знаком: матч проти до-фіксної версії — 12–0.
- Виправлено порядок ходів (бонус планів обмежений `[0,1]` та side-aware), історію
  (нормалізована під тактикою), терти (фаза з non-pawn матеріалу), LMR re-search,
  PV-бонус у корені, знак мата, TT-нормування мата, нічиї (claimable vs automatic),
  індексацію пішаків (`sq >> 4` → `1 << (7 - sq>>4)`), `forkBalance`, `spaceControlled`.
- Додано: `bench/match.mjs` (абляційний harness: W-D-L, score з 95% CI), `tests/engine.eval.mjs`,
  npm-скрипти `match:engine` / `match:ablate` / `match:depth`.
- Прибрано: панелі ρ_s, Belnap/морфізмів, S₀-діагностики, diffusion-генератора, teacher,
  telemetry, порівняння рушіїв.

## Виміряна сила (чесно)

| Твердження | Доказ |
|---|---|
| Виправлення перспективи дає великий приріст | 12–0 проти до-фіксних модулів (d3/d4) |
| Швидкий tier оцінки поки не виграє | 52.5% ± 13.3 (20 партій, d3) |
| Глибина поки не конвертується в силу | 45.8% ± 22.4 (12 партій, d5 vs d4) |
| Структурні шари поки не окупаються | 56.3% ± 34.3 (8 партій, base vs plain) |
| Кореневий хід — справжній argmax | звірка з brute-force на 3 позиціях: 8/109/82 |

Немає дебютної книги та варіативності: рівні партії з початкової позиції йдуть до
300-півневого cap. Це наступний крок, а не баг коректності (див. `docs/ROADMAP.md`, Gate 1).
