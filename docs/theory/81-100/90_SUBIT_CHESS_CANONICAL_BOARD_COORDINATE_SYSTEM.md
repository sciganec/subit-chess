# SUBIT-CHESS — CANONICAL BOARD COORDINATE SYSTEM

**Специфікація:** SC-CORE-COORD-001  
**Версія:** 1.0.0  
**Призначення:** Єдина система координат шахової дошки для всіх компонентів SUBIT-CHESS.  
**Статус:** CANONICAL — нормативна основа для FIELD DYNAMICS, MOVE GENERATION, POSITION EVALUATION та SEARCH.

## 1. Загальна орієнтація

Шахова дошка розглядається в стандартній орієнтації, коли білі перебувають унизу, а чорні — вгорі.

Канонічні напрямки:

- NORTH — у напрямку восьмої горизонталі.
- SOUTH — у напрямку першої горизонталі.
- EAST — у напрямку файлу h.
- WEST — у напрямку файлу a.

Схематичне представлення:

```text
             NORTH
               ↑
       a  b  c  d  e  f  g  h
    8  □  □  □  □  □  □  □  □
    7  □  □  □  □  □  □  □  □
    6  □  □  □  □  □  □  □  □
    5  □  □  □  □  □  □  □  □
    4  □  □  □  □  □  □  □  □
    3  □  □  □  □  □  □  □  □
    2  □  □  □  □  □  □  □  □
    1  □  □  □  □  □  □  □  □
       ───────────────────────→ EAST
      WEST

               ↓
             SOUTH
```

Схема показує напрямки координат, а не розташування фігур.

## 2. Координатна модель

Для кожної клітини визначається пара цілих координат:

q = (x,y)

Діапазони:

x ∈ {0,1,2,3,4,5,6,7}

y ∈ {0,1,2,3,4,5,6,7}

Вісь X:

- a = 0
- b = 1
- c = 2
- d = 3
- e = 4
- f = 5
- g = 6
- h = 7

Збільшення X означає рух EAST.

Зменшення X означає рух WEST.

Вісь Y:

- 1 = 0
- 2 = 1
- 3 = 2
- 4 = 3
- 5 = 4
- 6 = 5
- 7 = 6
- 8 = 7

Збільшення Y означає рух NORTH.

Зменшення Y означає рух SOUTH.

## 3. Канонічні координати

| Клітина | Координати |
|---|---|
| a1 | (0,0) |
| h1 | (7,0) |
| a8 | (0,7) |
| h8 | (7,7) |
| d4 | (3,3) |
| e4 | (4,3) |
| d5 | (3,4) |
| e5 | (4,4) |

Функція перетворення:

x = file_index

y = rank − 1

Зворотне перетворення:

file = 'a' + x

rank = y + 1

## 4. Канонічні вектори напрямків

Ортогональні напрямки:

NORTH = (0,+1)

SOUTH = (0,−1)

EAST = (+1,0)

WEST = (−1,0)

Діагональні напрямки:

NORTH_EAST = (+1,+1)

NORTH_WEST = (−1,+1)

SOUTH_EAST = (+1,−1)

SOUTH_WEST = (−1,−1)

Ця множина є незмінною для всієї архітектури двигуна.

## 5. Відношення напрямків до кольору

Напрямок руху пішаків залежить від кольору.

Для WHITE:

FORWARD = NORTH = (0,+1)

BACKWARD = SOUTH = (0,−1)

PAWN_ATTACK_FILE_DECREMENT = NORTH_WEST = (−1,+1)

PAWN_ATTACK_FILE_INCREMENT = NORTH_EAST = (+1,+1)

Для BLACK:

FORWARD = SOUTH = (0,−1)

BACKWARD = NORTH = (0,+1)

PAWN_ATTACK_FILE_DECREMENT = SOUTH_WEST = (−1,−1)

PAWN_ATTACK_FILE_INCREMENT = SOUTH_EAST = (+1,−1)

Важливо: позначення FILE_DECREMENT і FILE_INCREMENT визначають зміну координати X, а не ліву чи праву сторону відносно гравця.

Це усуває неоднозначність термінів LEFT та RIGHT для пішаків.

## 6. Незмінність системи координат

Координатна система не обертається:

- під час переходу від WHITE до BLACK;
- під час зміни сторони, що ходить;
- під час зміни перспективи відображення дошки;
- під час виконання рокірування;
- під час будь-якого іншого шахового ходу.

Координата e4 завжди відповідає (4,3).

NORTH завжди означає збільшення Y.

EAST завжди означає збільшення X.

## 7. Відокремлення логічних координат від індексації пам'яті

Внутрішня координатна система не повинна залежати від способу зберігання масиву в пам'яті або від графічного відображення дошки.

Наприклад, графічний інтерфейс або двовимірний масив можуть використовувати нульовий рядок угорі.

Це не змінює канонічної системи.

У такому випадку потрібне явне перетворення:

screen_row = 7 − y

або відповідний адаптер для конкретної структури пам'яті.

Усі математичні оператори повинні працювати з канонічними координатами, а не з координатами екрану.

## 8. Обов'язкове застосування

Ця система координат є нормативною для:

- FD-03 — VECTOR REPRESENTATION;
- FD-04 — DIRECTIONAL OPERATORS;
- FD-05 — GRADIENT OPERATOR;
- FD-06 — DIVERGENCE OPERATOR;
- FD-07 — CURL / CIRCULATION;
- MOVE GENERATION;
- ATTACK MAP;
- POSITION EVALUATION;
- SEARCH;
- шахового візуального інтерфейсу через окремий адаптер.

Жоден компонент не повинен самостійно визначати альтернативну систему координат.

## 9. Критерії відповідності

Компонент відповідає стандарту, якщо:

1. a1 завжди має координати (0,0).
2. h8 завжди має координати (7,7).
3. NORTH збільшує Y на одиницю.
4. SOUTH зменшує Y на одиницю.
5. EAST збільшує X на одиницю.
6. WEST зменшує X на одиницю.
7. Білий пішак рухається в напрямку NORTH.
8. Чорний пішак рухається в напрямку SOUTH.
9. Зміна сторони, що ходить, не змінює координатної системи.
10. Екранна індексація не змінює математичної орієнтації дошки.

**Канонічне правило:**

X = FILE (a → h)

Y = RANK (1 → 8)

EAST = +X

WEST = −X

NORTH = +Y

SOUTH = −Y

Ця конвенція є єдиною системою координат SUBIT-CHESS.
