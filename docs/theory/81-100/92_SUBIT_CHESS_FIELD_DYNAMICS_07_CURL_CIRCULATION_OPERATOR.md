**Специфікація:** SC-FD-001-FD07  
**Версія:** 0.7.0  
**Батьківський компонент:** FIELD DYNAMICS  
**Попередній документ:** FD-06 — DIVERGENCE OPERATOR  
**Наступний документ:** FD-08 — FIELD INTERACTION AND SUPERPOSITION  
**Пріоритет:** P0

# 1. Призначення

FD-07 вводить дискретний оператор циркуляції та його локальну форму — CURL.

Попередній компонент FD-06 визначив локальний баланс потоків:

Div J(v) = NetOutflow(v) / μ(v).

Це дозволяє встановити, чи переважає у вузлі вхідний або вихідний потік.

Однак дивергенція не описує повністю напрямлену структуру потоку.

Можливий випадок, коли:

Div J(v)=0

для всіх вузлів графа, але сам потік залишається ненульовим.

Наприклад, у замкненому циклі потік може рухатися без накопичення або втрати на кожному вузлі.

Саме цю характеристику повинен виявляти FD-07.

Основні завдання:

1. Визначити замкнені напрямлені контури.
2. Обчислювати циркуляцію вздовж контуру.
3. Визначати локальну циркуляцію навколо елементарної грані.
4. Формувати дискретне поле CURL.
5. Розрізняти потенціальну та циркуляційну структури.
6. Виявляти циклічні залежності між шаховими об'єктами.
7. Аналізувати зміни циркуляції після переміщення фігур.
8. Визначати роль перешкод у формуванні або руйнуванні циклів.
9. Перевіряти математичні співвідношення між градієнтом, дивергенцією та циркуляцією.
10. Підготувати математичну основу для наступного компонента FIELD INTERACTION.

FD-07 не повинен трактувати циркуляцію як фізичне обертання шахового впливу.

Це математична характеристика напрямленого поля на графовій структурі.

**Основне визначення:**

CIRCULATION — сумарний напрямлений внесок реберного поля вздовж заданого замкненого контуру.

CURL — локальна характеристика циркуляції відносно орієнтованої грані або іншого явно визначеного циклічного елемента.

# 2. Математична основа

## 2.1. Вихідна графова модель

Використовуємо граф:

G=(V,E).

Де:

V — множина вузлів;

E — множина орієнтованих ребер.

Для базової шахової дошки:

V=Q.

|Q|=64.

Кожен вузол відповідає одній клітині.

Кожне ребро представляє допустимий зв'язок між двома вузлами відповідно до обраної графової моделі.

Основний граф для локальної циркуляції:

G4.

Він містить горизонтальні та вертикальні зв'язки між сусідніми клітинами.

Діагональні зв'язки можуть бути додані через G8, але їхня топологічна роль повинна визначатися окремо.

## 2.2. Канонічна система координат

Використовується SC-CORE-COORD-001.

Координати:

q=(x,y).

Діапазони:

x∈{0,1,2,3,4,5,6,7}

y∈{0,1,2,3,4,5,6,7}.

Вісь X:

a=0, b=1, c=2, d=3, e=4, f=5, g=6, h=7.

Вісь Y:

1=0, 2=1, 3=2, 4=3, 5=4, 6=5, 7=6, 8=7.

Канонічні напрямки:

EAST=(+1,0)

WEST=(−1,0)

NORTH=(0,+1)

SOUTH=(0,−1)

NORTH_EAST=(+1,+1)

NORTH_WEST=(−1,+1)

SOUTH_EAST=(+1,−1)

SOUTH_WEST=(−1,−1).

Орієнтація контуру повинна визначатися відносно цієї системи координат, а не відносно кольору фігури.

## 2.3. Реберне поле

Нехай:

J:E→ℝ.

J(e) — знакове значення потоку на ребрі.

Позитивне значення відповідає канонічному напрямку ребра.

Негативне — протилежному напрямку.

Нульове — відсутності потоку відповідного типу.

Кожен потік повинен мати визначену семантику:

- STRUCTURAL_FLUX;
- ATTACK_RELATION_FLUX;
- DEFENSE_RELATION_FLUX;
- MOBILITY_FLUX;
- ACCESSIBILITY_FLUX;
- GRADIENT_INDUCED_FLUX;
- OTHER_TYPED_FLUX.

Не допускається обчислювати циркуляцію для невизначеного або семантично несумісного набору потоків.

# 3. Дискретна топологія: вузли, ребра та грані

Для коректного визначення локального CURL недостатньо лише графа вузлів і ребер.

Необхідно визначити також його грані.

Вводимо дискретний комплекс:

K=(V,E,F).

Де:

V — вузли;

E — ребра;

F — орієнтовані грані.

Це є основою для переходу від графового аналізу до дискретної топології.

## 3.1. Вузол

Вузол відповідає шаховій клітині.

Наприклад:

d4.

## 3.2. Ребро

Ребро відповідає зв'язку між двома суміжними вузлами.

Наприклад:

d4 → e4.

## 3.3. Грань

Грань — елементарна замкнена область, межа якої складається з послідовності ребер.

Для G4 кожна внутрішня елементарна грань має чотири вершини.

Наприклад:

d4 → e4 → e5 → d5 → d4.

Це елементарний квадратний контур.

## 3.4. Кількість елементарних граней

Для шахової дошки 8×8:

кількість вузлів = 64;

кількість горизонтальних ребер = 56;

кількість вертикальних ребер = 56;

загальна кількість ребер G4 = 112;

кількість елементарних квадратних граней = 49.

Отже:

|V|=64;

|E|=112;

|F|=49.

Для зв'язного планарного графа виконується формула Ейлера:

|V|−|E|+|F_total|=2.

Тут F_total включає також зовнішню грань.

Тому:

64−112+50=2.

Це важливий структурний інваріант для перевірки побудови базового графа.

---

# 4. Канонічна орієнтація граней

Для G4 кожна елементарна грань має канонічну орієнтацію проти годинникової стрілки.

Для клітин із нижнім лівим кутом (x,y):

v₀=(x,y)

v₁=(x+1,y)

v₂=(x+1,y+1)

v₃=(x,y+1).

Замкнений контур:

v₀ → v₁ → v₂ → v₃ → v₀.

У координатній системі дошки це означає:

EAST → NORTH → WEST → SOUTH.

Наприклад:

d4 → e4 → e5 → d5 → d4.

Ця орієнтація є канонічною.

Зворотний обхід має протилежний знак циркуляції.

## 4.1. Чому орієнтація важлива

Нехай потік уздовж кожного ребра має значення +1 відносно напрямку обходу.

Тоді циркуляція контуру дорівнює:

1+1+1+1=4.

Якщо обійти той самий контур у протилежному напрямку, результат буде:

−4.

Геометричний контур не змінився.

Змінилася лише його орієнтація.

Тому орієнтація є обов'язковою частиною структури Cycle.

# 5. Оператор CU-01 — CYCLE DEFINITION

## 5.1. Призначення

CU-01 визначає замкнений контур на графі.

Контур:

C=(v₀,e₁,v₁,e₂,...,eₙ,vₙ).

Умова замкненості:

vₙ=v₀.

Кожне ребро повинно з'єднувати відповідну пару послідовних вузлів.

## 5.2. Вимоги до циклу

Цикл повинен містити:

- початковий вузол;
- послідовність ребер;
- послідовність вузлів;
- орієнтацію;
- довжину;
- графову область;
- контекст;
- provenance.

## 5.3. Простий цикл

Простий цикл не повинен повторювати вузли, окрім початкового вузла в кінці.

Наприклад:

a1 → b1 → b2 → a2 → a1.

Це простий цикл.

Маршрут:

a1 → b1 → a1 → b1

не є простим циклом.

## 5.4. Елементарний цикл

Елементарний цикл — цикл, який не містить іншого циклу всередині відповідно до обраного графового комплексу.

Для базового G4 елементарними є квадратні грані.

Однак не всі цикли повинні бути елементарними.

Наприклад, контур:

a1 → b1 → c1 → c2 → c3 → b3 → a3 → a2 → a1

є більшим замкненим контуром.

Він може бути важливим для аналізу регіональної циркуляції.

## 5.5. Ідентифікація

Cycle повинен мати стабільний ідентифікатор:

cycle_id.

Ідентифікатор повинен враховувати:

- граф;
- множину ребер;
- канонічну орієнтацію;
- тип циклу.

Однаковий геометричний цикл із протилежною орієнтацією повинен мати різне представлення орієнтації, але може посилатися на той самий неорієнтований цикл.

# 6. Оператор CU-02 — CIRCULATION

## 6.1. Основне визначення

Для замкненого контуру C визначимо циркуляцію:

Circ(J,C)=Σ σ(e,C)·J(e).

Де:

σ(e,C)=+1, якщо напрямок ребра збігається з напрямком обходу;

σ(e,C)=−1, якщо напрямок ребра протилежний;

σ(e,C)=0, якщо ребро не належить контуру.

Це основна формула циркуляції FD-07.

## 6.2. Інтерпретація

Позитивна циркуляція означає переважання потоку в напрямку канонічного обходу.

Негативна — переважання потоку у зворотному напрямку.

Нульова — алгебраїчний баланс уздовж контуру.

Нульова циркуляція не обов'язково означає, що всі реберні потоки дорівнюють нулю.

Вони можуть бути ненульовими, але взаємно компенсуватися.

## 6.3. Приклад

Розглянемо цикл:

a1 → b1 → b2 → a2 → a1.

Задамо:

J(a1→b1)=2;

J(b1→b2)=3;

J(a2→b2)=1;

J(a1→a2)=1.

Останні два ребра в канонічному представленні можуть мати протилежний напрямок до обходу циклу.

Тоді внески:

a1→b1: +2;

b1→b2: +3;

b2→a2: −1;

a2→a1: −1.

Отже:

Circ(J,C)=2+3−1−1=3.

## 6.4. Зворотна орієнтація

Для того самого циклу:

Circ(J,−C)=−Circ(J,C).

Це обов'язковий інваріант.

## 6.5. Нормалізована циркуляція

Для порівняння циклів різної довжини може використовуватися:

Circ_avg(J,C)=Circ(J,C)/L(C).

Де L(C) — сумарна довжина контуру.

Це середній алгебраїчний потік на одиницю довжини.

Він не замінює повну циркуляцію.

Обидва значення повинні зберігатися окремо.

# 7. Оператор CU-03 — DISCRETE CURL

## 7.1. Призначення

CU-03 визначає локальну циркуляцію навколо елементарної грані.

Для кожної грані f:

Curl J(f)=Circ(J,∂f)/Area(f).

Де:

∂f — орієнтована межа грані;

Area(f) — площа грані відповідно до вибраної метрики.

## 7.2. Базова модель G4

Для стандартної шахової дошки:

Area(f)=1.

Тому:

Curl J(f)=Circ(J,∂f).

Для грані:

d4 → e4 → e5 → d5 → d4

отримуємо:

Curl J(f)=

J(d4→e4)

+J(e4→e5)

−J(d5→e5)

−J(d4→d5).

Формула враховує канонічні напрямки ребер EAST та NORTH.

## 7.3. Знак CURL

Позитивний CURL означає позитивну циркуляцію відносно канонічної орієнтації грані.

Негативний CURL означає протилежну циркуляцію.

Нульовий CURL означає нульову сумарну циркуляцію навколо цієї грані.

## 7.4. Відмінність між CURL та CIRCULATION

CIRCULATION — характеристика цілого замкненого контуру.

CURL — локальна характеристика циркуляції відносно елементарної грані.

Отже:

CIRCULATION працює з циклом C.

CURL працює з орієнтованою гранню f.

Для базової квадратної сітки вони пов'язані, але не є тотожними поняттями.

# 8. Оператор CU-04 — FACE INCIDENCE

## 8.1. Призначення

CU-04 формує відношення між ребрами та гранями.

Для кожної грані визначається послідовність орієнтованих ребер її межі.

Вводиться матриця:

D₁(f,e).

Значення:

+1 — якщо орієнтація ребра збігається з орієнтацією межі грані;

−1 — якщо орієнтація протилежна;

0 — якщо ребро не належить межі грані.

Тоді вектор локальної циркуляції:

CURL = D₁·J.

Для одиничних квадратних граней G4 площа дорівнює одиниці, тому нормалізація не змінює результат.

## 8.2. Зв'язок із матрицею інцидентності FD-06

FD-06 використовував матрицю:

B(v,e).

Вона пов'язує вузли та ребра.

FD-07 вводить:

D₁(f,e).

Вона пов'язує грані та ребра.

Це формує повний дискретний комплекс:

ВУЗЛИ → РЕБРА → ГРАНІ.

Математично:

C⁰(K) → C¹(K) → C²(K).

Де:

C⁰ — скалярні значення на вузлах;

C¹ — напрямлені значення на ребрах;

C² — циркуляційні значення на гранях.

Це не просто три масиви даних.

Це три різні рівні дискретної геометричної структури.

## 8.3. Фундаментальний інваріант

Для коректного комплексу:

D₁·Bᵀ=0.

Це дискретний аналог співвідношення:

curl(grad φ)=0.

Іншими словами, градієнт скалярного поля не повинен створювати ненульову циркуляцію навколо замкненої елементарної грані.

Це один із найважливіших тестів FD-07.

# 9. Оператор CU-05 — GRADIENT-CURL CONSISTENCY

## 9.1. Призначення

CU-05 перевіряє сумісність FD-05 та FD-07.

Нехай:

φ:V→ℝ.

Градієнт на ребрі:

Gradφ(u→v)=φ(v)−φ(u).

Для одиничних ребер G4.

Розглянемо замкнений контур:

v₀ → v₁ → v₂ → v₃ → v₀.

Тоді:

Circ(Gradφ,C)=

[φ(v₁)−φ(v₀)]

+[φ(v₂)−φ(v₁)]

+[φ(v₃)−φ(v₂)]

+[φ(v₀)−φ(v₃)].

Після скорочення:

Circ(Gradφ,C)=0.

Отже:

CURL(GRAD φ)=0.

## 9.2. Значення для SUBIT-CHESS

Це означає, що якщо напрямлене поле справді отримане як градієнт одного скалярного поля, воно повинно мати нульову циркуляцію вздовж кожного замкненого контуру, для якого визначена відповідна дискретна геометрія.

Якщо тест не проходить, можливі причини:

- помилка орієнтації ребер;
- некоректне формування циклу;
- неправильне обчислення градієнта;
- несумісна метрика;
- помилка матриці інцидентності;
- некоректне зіставлення вузлів і граней.

## 9.3. Важливе обмеження

Нульова циркуляція є необхідною властивістю градієнтного поля.

Але для загального графа питання про достатність цієї умови залежить від топології графа та його циклічного простору.

Тому не можна стверджувати, що будь-яке поле з нульовим CURL автоматично є глобальним градієнтом без додаткових умов.

# 10. Оператор CU-06 — LOCAL CURL FIELD

## 10.1. Призначення

CU-06 формує повне поле локальної циркуляції на всій шаховій дошці.

Для базового G4 існує 49 елементарних граней.

Кожна грань отримує власне значення CURL.

## 10.2. Структура

CurlField = (

curl_id,

flux_id,

domain_id,

face_values,

orientation,

metric_id,

context_id,

position_id,

validity,

provenance,

version

).

## 10.3. Представлення

Для кожної грані:

FaceCurl = (

face_id,

vertices,

boundary_edges,

signed_circulation,

area,

curl_value,

classification,

validity

).

## 10.4. Класифікація

POSITIVE_CURL:

Curl(f)>0.

NEGATIVE_CURL:

Curl(f)<0.

ZERO_CURL:

Curl(f)=0.

UNDEFINED_CURL:

недостатньо даних.

PARTIAL_CURL:

частина реберних значень відома, але повне значення не визначене.

STALE_CURL:

результат належить до попередньої версії позиції.

## 10.5. Невідомі значення

Якщо одне з ребер грані має невідомий потік, повний CURL цієї грані не можна автоматично обчислювати так, ніби це ребро має нульове значення.

Результат:

UNDEFINED_CURL або PARTIAL_CURL.

Це продовжує принцип FD-02:

UNKNOWN ≠ ZERO.

# 11. Оператор CU-07 — CYCLE SPACE

## 11.1. Призначення

CU-07 визначає простір циклів графа.

Це необхідно для аналізу замкнених структур, які не обов'язково збігаються з елементарними квадратними гранями.

## 11.2. Циклічний простір

Для графа G=(V,E) цикл — замкнена послідовність ребер.

Множина всіх циклів формує циклічний простір графа.

Для зв'язного графа його розмірність:

β₁=|E|−|V|+1.

Для G4:

β₁=112−64+1=49.

Це збігається з кількістю елементарних квадратних граней.

Для базового прямокутного планарного графа G4 елементарні грані утворюють базис циклічного простору.

## 11.3. Циклічний базис

Вводиться:

CycleBasis(G).

Це множина незалежних циклів, через які можна представити будь-який цикл графа як комбінацію базисних циклів.

Для G4 можна використовувати 49 елементарних квадратних циклів.

Для інших графів базис повинен будуватися окремо.

## 11.4. Навіщо потрібен базис

Без циклічного базису двигун може багаторазово обчислювати циркуляцію для циклів, які є комбінаціями інших циклів.

Це створює зайві обчислення та дублювання.

Базис дозволяє:

- компактно представляти циклічну структуру;
- перевіряти незалежність циклів;
- порівнювати циркуляцію;
- виявляти нові циклічні залежності;
- будувати локальні та регіональні карти.

## 11.5. Неоднозначність базису

Циклічний базис не є єдиним.

Різні алгоритми можуть сформувати різні базиси одного графа.

Тому:

- вибір алгоритму повинен бути явним;
- базис повинен мати ідентифікатор;
- порядок циклів повинен бути детермінованим;
- порівняння базисів повинно враховувати їхню еквівалентність, а не лише послідовність елементів.

# 12. Оператор CU-08 — CIRCULATION DECOMPOSITION

## 12.1. Призначення

CU-08 аналізує, наскільки реберне поле містить циклічну складову.

Важливо не плутати цей оператор із безпосереднім обчисленням CURL.

CURL визначає локальну циркуляцію.

CIRCULATION DECOMPOSITION досліджує розкладання поля на структурні компоненти.

## 12.2. Потенціальна компонента

Для скалярного поля φ визначається:

J_grad=Gradφ.

Ця компонента формується з різниць потенціалу між вузлами.

Її циркуляція на замкненому контурі дорівнює нулю.

## 12.3. Циклічна компонента

Для циклічної компоненти J_cycle характерне ненульове значення циркуляції хоча б на деяких циклах.

Однак сама наявність ненульової циркуляції не означає, що весь потік можна однозначно поділити на просту пару:

GRADIENT + CYCLE.

Для загального графа потрібна додаткова структура, наприклад внутрішній добуток на реберному просторі.

## 12.4. Графовий розклад Годжа

За наявності визначених метрик на просторах вузлів, ребер і граней можна використовувати дискретний аналог розкладу Годжа.

У двовимірному орієнтованому комплексі реберне поле може мати компоненти:

J = Gradφ + Curl*ψ + H.

Де:

Gradφ — градієнтна компонента;

Curl*ψ — компонента, дуальна до градієнта на гранях;

H — гармонічна компонента.

Тут Curl* позначає відповідний спряжений оператор, а не повторне застосування локального CURL.

Точна форма залежить від вибраних метрик та операторів.

## 12.5. Гармонічна компонента

H — компонента, яка не виявляється простими градієнтними або ко-градієнтними внесками.

Вона може бути пов'язана з топологічними особливостями області.

Для повної прямокутної шахової дошки без отворів базова топологія проста.

Але якщо потокова область визначається через обмеження, видалення вузлів або спеціальні зв'язки, її топологічна структура може змінитися.

Тому гармонічну компоненту не можна ігнорувати в загальному випадку.

## 12.6. Обмеження реалізації

Повний розклад Годжа не є обов'язковою частиною першої реалізації FD-07.

Перший етап повинен реалізувати:

- цикли;
- циркуляцію;
- локальний CURL;
- матрицю інцидентності;
- перевірку gradient-curl consistency.

Розклад Годжа повинен бути окремим розширенням після перевірки базової моделі.

# 13. Оператор CU-09 — BLOCKER-INDUCED CIRCULATION

## 13.1. Призначення

CU-09 аналізує зміну циклічної структури через появу або переміщення перешкод.

Перешкода може:

- видаляти ребра зі спеціалізованого графа;
- змінювати вагу ребер;
- розривати доступний контур;
- створювати альтернативний цикл;
- змінювати потокові значення.

## 13.2. Важливе розмежування

Геометрична грань шахової дошки існує незалежно від розташування фігур.

Перешкода не знищує геометричну клітину або квадратну грань.

Вона може лише змінювати конкретну потокову модель або доступність зв'язків у спеціалізованому графі.

Тому потрібно розділяти:

BOARD_TOPOLOGY

і

POSITION_DEPENDENT_FLUX_TOPOLOGY.

## 13.3. Приклад

Розглянемо цикл:

d4 → e4 → e5 → d5 → d4.

Якщо потокова проєкція залежить від певного лінійного зв'язку, переміщення фігури на одну з клітин може змінити потоки на відповідних ребрах.

Але сама квадратна грань G4 залишається.

Це дозволяє відрізнити:

- зміну топології графа;
- зміну активності ребер;
- зміну значень потоку;
- зміну локальної циркуляції.

## 13.4. Результат

BlockerCirculationDelta містить:

- попередній цикл;
- новий цикл;
- змінені ребра;
- змінені потокові значення;
- старий CURL;
- новий CURL;
- різницю;
- ідентифікатор перешкоди;
- provenance.

# 14. Оператор CU-10 — CIRCULATION TRANSFORMATION DELTA

## 14.1. Призначення

CU-10 визначає зміну циркуляції після шахового ходу.

Нехай:

S₀ — початкова позиція;

m — хід;

S₁=Tₘ(S₀).

Тоді:

J₀=J(S₀);

J₁=J(S₁).

Для одного й того самого сумісного циклу C:

ΔCirc(C)=Circ(J₁,C)−Circ(J₀,C).

Для елементарної грані:

ΔCurl(f)=Curl(J₁,f)−Curl(J₀,f).

## 14.2. Класи змін

CIRCULATION_INCREASED

CIRCULATION_DECREASED

CIRCULATION_SIGN_CHANGED

CIRCULATION_ZEROED

CIRCULATION_CREATED

CIRCULATION_DESTROYED

CURL_PATTERN_CHANGED

CYCLE_STRUCTURE_CHANGED

CYCLE_BASIS_CHANGED

## 14.3. Сумісність порівняння

Для порівняння повинні збігатися:

- тип потоку;
- орієнтація;
- графова область;
- метрика;
- правило побудови потоку;
- спосіб нормалізації;
- контекст.

Якщо змінено сам цикл або граф, необхідно окремо визначити відповідність між старою та новою структурою.

Не можна порівнювати два несумісні цикли як одну й ту саму величину.

## 14.4. Інкрементальне оновлення

Після ходу потрібно:

1. Визначити змінені фігури.
2. Визначити залежні напрямлені відношення.
3. Визначити ребра, на які вплинули ці відношення.
4. Оновити потокові значення.
5. Перерахувати циркуляцію лише для залежних циклів.
6. Оновити відповідні грані.
7. Перевірити актуальність циклічного базису.
8. Зберегти provenance.

Для перевірки інкрементальний результат повинен збігатися з повним перерахунком.

# 15. Спеціалізовані графи шахових фігур

Окремий важливий аспект FD-07 — застосування циркуляції до графів, які не збігаються з геометричною сіткою G4.

## 15.1. Rook Graph

Тура переміщується вздовж горизонталей і вертикалей.

Для потокової моделі тури можна визначити лінійні графи, у яких вузли представляють клітини, а ребра — сусідні клітини відповідного відкритого променя.

Цикли можуть виникати через перетини горизонтальних і вертикальних зв'язків.

Однак конкретні активні ребра залежать від зайнятості клітин та правил проєкції.

## 15.2. Bishop Graph

Слон переміщується діагональними напрямками.

Його граф має іншу структуру суміжності.

Діагональні зв'язки не можна безпідставно змішувати з ортогональними ребрами G4.

Для слона необхідно визначити окремий граф:

G_bishop.

Цей граф може містити різні зв'язні компоненти, оскільки слон зберігає колір клітини.

## 15.3. Queen Graph

Граф ферзя поєднує ортогональні та діагональні зв'язки.

Його ребра повинні зберігати тип напрямку.

Не можна втрачати інформацію про те, чи відповідне відношення сформоване горизонтальним, вертикальним або діагональним рухом.

## 15.4. Knight Graph

Кінь використовує стрибкоподібні переходи.

Його ребро може представляти переміщення:

(±1,±2)

або

(±2,±1).

Граф коня не є планарним у звичайному геометричному представленні дошки.

Тому локальна квадратна CURL-модель G4 не може автоматично застосовуватися до нього.

Для коня необхідно використовувати циклічний простір графа.

Циркуляція може обчислюватися вздовж циклів графа коня:

Circ(J,C)=Σσ(e,C)·J(e).

Але локальний CURL потребує додаткової структури граней або визначеного циклічного базису.

## 15.5. King Graph

Король переміщується на одну клітину в будь-якому напрямку.

Його геометричний граф суміжності може відповідати G8.

Проте спеціальні правила рокірування не повинні автоматично включатися в локальний граф короля як звичайні ребра.

Рокірування — окрема легальна трансформація стану, яка потребує власної потокової проєкції.

## 15.6. Загальна вимога

Кожен спеціалізований граф повинен мати:

- власний domain_id;
- визначені вузли;
- визначені ребра;
- орієнтацію;
- цикл або цикл-базис;
- метрику;
- семантику потоку;
- правила доступності;
- provenance.

Результати різних графів не можна агрегувати без окремого оператора узгодження.

# 18. Дискретна теорема Стокса

Це одна з центральних математичних основ FD-07.

## 18.1. Основне твердження

Для орієнтованої області Z, складеної з елементарних граней:

Σ Curl(J,f)·Area(f) = Circ(J,∂Z).

Ліва частина — сума локальних циркуляцій усіх граней області.

Права частина — циркуляція вздовж зовнішньої межі області.

## 18.2. Чому це працює

Кожне внутрішнє ребро належить межам двох сусідніх граней.

Для однієї грані його орієнтація буде позитивною.

Для іншої — негативною.

Тому внутрішні внески скорочуються.

Залишаються лише ребра зовнішньої межі.

Це і є дискретний аналог теореми Стокса.

## 18.3. Приклад

Розглянемо область, утворену чотирма квадратними гранями.

Нехай:

f₁, f₂, f₃, f₄.

Тоді:

Circ(J,∂Z)=

Curl(J,f₁)

+Curl(J,f₂)

+Curl(J,f₃)

+Curl(J,f₄)

для одиничних граней за узгодженої орієнтації.

Внутрішні ребра не повинні давати додатковий сумарний внесок.

## 18.4. Призначення в SUBIT-CHESS

Це дозволяє перевіряти, чи відповідає локальна карта CURL циркуляції вздовж межі відповідної структурної зони.

Це також забезпечує незалежний спосіб виявлення помилок у:

- орієнтації ребер;
- орієнтації граней;
- побудові циклів;
- інцидентності;
- обчисленні локальної циркуляції.

# 19. Взаємодія з FD-05 та FD-06

## 19.1. Зв'язок із градієнтом

FD-05 формує:

Gradφ.

FD-07 перевіряє:

CURL(Gradφ)=0.

Це основний інваріант сумісності.

## 19.2. Зв'язок із дивергенцією

FD-06 формує:

Div J.

FD-07 формує:

Curl J.

Ці два оператори описують різні властивості поля.

Дивергенція:

- локальний баланс;
- вихідний потік;
- вхідний потік;
- джерельні та стокові вузли.

Циркуляція:

- замкнені контури;
- напрямлений обхід;
- локальні циклічні характеристики;
- просторові циклічні залежності.

## 19.3. Два незалежні виміри

Можливі чотири базові випадки:

**Випадок A: Div≠0, Curl≠0**

Поле має локальний дисбаланс і ненульову локальну циркуляцію.

**Випадок B: Div≠0, Curl=0**

Поле має локальний дисбаланс, але нульову циркуляцію на відповідних гранях.

**Випадок C: Div=0, Curl≠0**

Поле локально збалансоване, але має ненульову циклічну структуру.

**Випадок D: Div=0, Curl=0**

Поле не має локальної дивергенції та локальної циркуляції в межах перевіреної моделі.

Останній випадок не означає автоматично, що саме поле нульове.

Для цього потрібні додаткові умови.

# 24. Тестова специфікація

## 24.1. Тест квадратного циклу

Створити цикл:

a1 → b1 → b2 → a2 → a1.

Встановити потік +1 уздовж кожного ребра в напрямку обходу.

Очікується:

Circ=4.

## 24.2. Тест зворотного обходу

Для того самого циклу виконати обхід у зворотному напрямку.

Очікується:

Circ=−4.

## 24.3. Тест нульової циркуляції

Встановити:

J₁=4;

J₂=−4;

J₃=2;

J₄=−2

відповідно до напрямку обходу.

Очікується:

Circ=0.

При цьому окремі реберні потоки залишаються ненульовими.

## 24.4. Тест локального CURL

Створити одну квадратну грань:

d4 → e4 → e5 → d5 → d4.

Надати ребрам довільні знакові значення.

Очікується, що CURL дорівнює алгебраїчній сумі внесків уздовж орієнтованої межі.

## 24.5. Тест протилежних орієнтацій

Створити дві копії однієї грані з протилежними орієнтаціями.

Очікується:

Curl(f_reverse)=−Curl(f).

## 24.6. Тест градієнта

Створити скалярне поле:

φ(x,y)=x+2y.

Обчислити градієнт на всіх ребрах G4.

Обчислити циркуляцію навколо кожної квадратної грані.

Очікується:

Curl(Gradφ)=0.

## 24.7. Тест константного поля

Встановити:

φ(q)=5

для всіх вузлів.

Очікується:

Gradφ=0;

Curl(Gradφ)=0.

## 24.8. Тест дискретної теореми Стокса

Визначити область із кількох суміжних квадратних граней.

Обчислити CURL кожної грані.

Підсумувати локальні циркуляції.

Окремо обчислити циркуляцію вздовж зовнішньої межі області.

Очікується повна рівність двох результатів.

## 24.9. Тест циклічного базису G4

Побудувати G4.

Очікується:

|V|=64;

|E|=112;

β₁=49.

Побудований циклічний базис повинен містити 49 незалежних циклів.

## 24.10. Тест матриць інцидентності

Побудувати:

B — матрицю вузлів та ребер;

D₁ — матрицю граней та ребер.

Перевірити:

D₁·Bᵀ=0.

## 24.11. Тест ненульового потоку з нульовим CURL

Створити градієнтне поле:

J=Gradφ.

Для невиродженого скалярного поля окремі реберні значення можуть бути ненульовими.

Очікується:

J≠0;

Curl(J)=0.

Цей тест перевіряє, що двигун не прирівнює нульовий CURL до нульового поля.

## 24.12. Тест ненульової циркуляції з нульовою дивергенцією

Створити орієнтований квадратний цикл з однаковим позитивним потоком на всіх ребрах обходу.

Очікується:

Div(J,v)=0

для кожного вузла циклу.

Водночас:

Circ(J,C)>0.

Це фундаментальний тест розрізнення FD-06 та FD-07.

## 24.13. Тест незалежності кольорових каналів

Створити окремі поля:

J_WHITE;

J_BLACK.

Змінити значення WHITE.

Очікується, що результат BLACK не зміниться.

Повторити у зворотному напрямку.

## 24.14. Тест блокування лінії

Створити позицію, де тура має відкриту горизонталь.

Додати перешкоду на цій лінії.

Перерахувати потокове поле та залежні цикли.

Очікується:

- коректна зміна потоків;
- правильне оновлення CURL;
- відсутність помилкового видалення геометричних граней дошки;
- правильне збереження provenance.

## 24.15. Тест графа коня

Побудувати G_knight.

Визначити цикл із кінських переходів.

Обчислити циркуляцію на цьому циклі.

Очікується:

- коректна замкненість;
- коректний знак;
- відсутність штучних проміжних клітин;
- відсутність автоматичного використання квадратних граней G4.

## 24.16. Тест трансформації після ходу

Обчислити CurlField для S₀.

Виконати легальний хід.

Отримати S₁.

Оновити залежні потокові поля.

Очікується:

- правильне оновлення циклів;
- правильне оновлення локального CURL;
- відсутність застарілих результатів;
- відповідність повному перерахунку;
- правильний provenance.

# 26. Обмеження FD-07

FD-07 не визначає:

- фізичне обертання шахового впливу;
- матеріальну силу фігур;
- стратегічну вигідність циркуляції;
- автоматичну перевагу циклічних структур;
- оптимальну траєкторію атаки;
- тактичну цінність кожного циклу;
- повний розклад Годжа для всіх можливих графів;
- універсальну топологію всіх спеціалізованих графів;
- остаточну оцінку позиції.

Особливо важливо:

**CURL ≠ STRATEGIC ADVANTAGE.**

**CIRCULATION ≠ PIECE MOBILITY.**

**CYCLE ≠ LEGAL MOVE SEQUENCE.**

Цикл у графі може бути математично замкненим, але це не означає, що шахова фігура може виконати відповідну послідовність ходів, не порушуючи правил гри.

Графова циклічність і легальна послідовність ходів повинні залишатися окремими структурами.

# 28. Висновок

FD-07 вводить дискретну циркуляцію та CURL у SUBIT-CHESS.

Основні формули:

**Циркуляція:**

Circ(J,C)=Σ σ(e,C)·J(e).

**Локальний CURL:**

Curl J(f)=Circ(J,∂f)/Area(f).

**Градієнтно-циркуляційний інваріант:**

CURL(GRAD φ)=0.

**Дискретна теорема Стокса:**

Σ Curl(J,f)·Area(f)=Circ(J,∂Z).

**Циклічний простір зв'язного графа:**

β₁=|E|−|V|+1.

Ці конструкції формують основу для аналізу циклічних характеристик шахових структур.

Водночас FD-07 зберігає принципову відмінність між:

- математичним циклом;
- легальною послідовністю шахових ходів;
- геометричною суміжністю;
- спеціалізованим графом фігури;
- напрямленим потоковим полем.

Це необхідно для того, щоб математичний апарат не підміняв собою правила шахів.
