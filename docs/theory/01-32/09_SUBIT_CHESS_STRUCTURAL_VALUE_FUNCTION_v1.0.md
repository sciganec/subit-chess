# 1. Анотація

SUBIT-CHESS STRUCTURAL VALUE FUNCTION (SVF) визначає спосіб перетворення шахової позиції на багатовимірне представлення її стратегічної, тактичної та структурної цінності.

У традиційній шаховій оцінці позиція часто представляється скалярним числом, яке приблизно відображає перевагу однієї зі сторін.

SUBIT-CHESS зберігає скалярну оцінку для потреб пошуку, але не обмежує внутрішнє представлення позиції одним числом.

Позиція розглядається як динамічна система взаємопов'язаних елементів:

- фігур;
- полів;
- геометричних можливостей;
- атак;
- захисту;
- обмежень;
- залежностей;
- структурних конфігурацій;
- тактичних загроз;
- контекстів;
- можливих трансформацій.

Тому функція оцінювання має два рівні:

1. **Структурний рівень** — формування багатовимірного опису позиції.
2. **Оціночний рівень** — визначення відносної цінності цього опису для сторін.

Основна формула:

`SVF(P, s; θ) = Scalarize(Ω(P), C(P), D(P), s; θ)`

де:

- P — шахова позиція;
- s — сторона, з перспективи якої оцінюється позиція;
- Ω(P) — структурне представлення;
- C(P) — контекст;
- D(P) — динамічні характеристики;
- θ — параметри оцінювання.

Функція не замінює шахові правила, легальність ходів або пошуковий алгоритм.

Вона надає пошуковому алгоритму інформацію для порівняння позицій.

# 2. Онтологічна основа

## 2.1. Позиція як структурна система

Шахова позиція — це не просто розташування фігур на 64 полях.

Вона містить щонайменше:

- розташування фігур;
- сторону, що ходить;
- права на рокіровку;
- можливість взяття en passant;
- лічильник напівходів;
- номер ходу;
- історію, необхідну для визначення повторень та інших історично залежних правил.

Позначимо:

`P = (B, s, C, E, H, N, 𝓗)`

де:

- B — дошка;
- s — сторона, що ходить;
- C — права на рокіровку;
- E — en passant;
- H — лічильник напівходів;
- N — номер повного ходу;
- 𝓗 — необхідна історія позиції.

Останній компонент принциповий: дві однакові за розташуванням фігур позиції можуть мати різний статус щодо повторення або інших історично залежних правил.

## 2.2. Структурне представлення

Визначимо:

`Ω(P) = (F, R, A, M, K, T, Q, X)`

де:

- F — множина фігур;
- R — множина відносин;
- A — множина атакувальних характеристик;
- M — мобільність;
- K — критичні властивості;
- T — тактичні конфігурації;
- Q — просторові характеристики;
- X — потенційні трансформації.

Це не просто набір незалежних оцінок.

Компоненти взаємодіють між собою.

Наприклад, мобільність фігури залежить від розташування інших фігур, контролю полів, блокувань та можливих тактичних наслідків.

## 2.3. Структура і цінність

Необхідно розрізняти:

`Ω(P) ≠ SVF(P)`

Структура описує, що існує в позиції.

Функція цінності оцінює, яке значення ця структура має для конкретної сторони.

Це розділення є фундаментальним.

Якщо змішати опис позиції з її оцінкою, система ризикує закодувати власні упередження безпосередньо у структурному представленні.

# 3. Сторони та перспективи

## 3.1. Абсолютне представлення

Спочатку визначимо абсолютний структурний вектор:

`V_abs(P) = (V_W(P), V_B(P))`

де:

- V_W — характеристики позиції з перспективи білих;
- V_B — характеристики позиції з перспективи чорних.

Кожна сторона отримує окремий опис:

- матеріального стану;
- мобільності;
- атак;
- захисту;
- структури;
- безпеки короля;
- просторового контролю;
- тактичних можливостей.

## 3.2. Відносна оцінка

Відносний вектор:

`ΔV(P) = V_W(P) − V_B(P)`

Це векторна різниця, а не обов'язково одне число.

Вона може містити:

`ΔV = (ΔM, ΔA, ΔR, ΔK, ΔT, ΔQ, ΔX)`

де:

- ΔM — матеріальна різниця;
- ΔA — різниця активності;
- ΔR — структурна різниця;
- ΔK — різниця безпеки королів;
- ΔT — тактична різниця;
- ΔQ — просторова різниця;
- ΔX — різниця потенціалу трансформацій.

## 3.3. Перспективна оцінка

Для сторони s:

`SVF(P, WHITE) = E(P)`

`SVF(P, BLACK) = −E(P)`

Ця властивість має виконуватися для скалярної оцінки в симетричній моделі.

Для negamax:

`V(P,d) = maxₘ [−V(T(P,m),d−1)]`

Функція оцінювання повинна бути узгоджена з цією зміною перспективи.

# 4. Архітектура структурної цінності

Пропонується розділити оцінювання на сім взаємопов'язаних вимірів.

## 4.1. Матеріальна цінність — M

Матеріал залишається важливим, але не є достатнім критерієм.

`M(P) = Σᶠ v(f)`

Для відносної оцінки:

`ΔM(P) = M_W(P) − M_B(P)`

Матеріальні ваги можуть залежати від фази партії.

Наприклад, цінність пішака може змінюватися залежно від його близькості до перетворення.

Але точний матеріальний склад позиції не повинен змішуватися з евристичною оцінкою активності фігур.

## 4.2. Функціональна цінність — A

Цей вимір описує, наскільки ефективно фігури виконують свої функції.

Він включає:

- мобільність;
- активність;
- координацію;
- доступ до важливих полів;
- можливість взаємодії;
- здатність створювати загрози.

Для фігури f:

`A(f,P) = g(mobility, activity, coordination, access)`

Для сторони:

`A_s(P) = Σᶠ∈s A(f,P)`

Важливо: функціональна активність не повинна оцінюватися лише кількістю доступних ходів.

Хід може бути легальним, але позиційно поганим.

## 4.3. Структурна цінність — R

Структурний вимір описує відносини між елементами позиції.

Він спирається на SRA.

До нього належать:

- підтримка;
- захист;
- зв'язність;
- обмеження;
- блокування;
- залежності;
- контроль;
- взаємна вразливість;
- структурна стійкість.

Нехай:

`R(P) = Σᵣ∈Relations(P) wᵣ · φᵣ(P)`

де:

- wᵣ — параметрична вага;
- φᵣ — характеристика конкретного відношення.

Відносини повинні залишатися типізованими.

Наприклад, контроль поля не тотожний захисту фігури.

Зв'язок між двома фігурами не обов'язково означає їхню взаємну підтримку.

## 4.4. Безпека короля — K

Король має особливий статус, тому його безпека повинна оцінюватися окремо.

`K(P) = g(check_status, attack_exposure, escape_squares, defenders, king_zone)`

Складові:

- поточний шах;
- кількість і якість атак на зону короля;
- доступні поля відступу;
- захищеність;
- відкритість ліній;
- можливість створення матової мережі.

Точний факт шаху визначається правилами.

Евристична функція оцінює ступінь небезпеки поза вже встановленими термінальними станами.

Мат не можна замінювати великим від'ємним числом евристичної оцінки, якщо пошуковий алгоритм має окремий точний механізм визначення мату.

## 4.5. Тактична цінність — T

Тактичний вимір характеризує конкретні можливості та загрози.

Він включає:

- вилки;
- зв'язування;
- відкриті атаки;
- подвійні загрози;
- перевантаження;
- відволікання;
- проміжні ходи;
- матові загрози;
- форсовані послідовності.

`T(P) = g(tactical_patterns, forcing_moves, vulnerabilities)`

Однак тактичний потенціал не можна просто додавати до матеріального балансу.

Якщо тактична комбінація вже врахована через пошук, повторне додавання її повної матеріальної вигоди може спричинити подвійний облік.

Тому тактична оцінка повинна враховувати горизонт пошуку та ступінь підтвердження загрози.

## 4.6. Просторова цінність — Q

Цей вимір описує розподіл контролю та можливостей у просторі.

`Q(P) = g(center, zones, files, diagonals, outposts, restrictions)`

Він включає:

- контроль центру;
- відкриті та напіввідкриті лінії;
- контроль діагоналей;
- форпости;
- просторові обмеження;
- територіальну активність.

Просторовий контроль не є абсолютною цінністю.

Важливо враховувати, чи може сторона реально використати контрольовану зону.

## 4.7. Потенціал трансформації — X

Це особливий компонент SUBIT-CHESS.

Він описує не лише поточну структуру, а й можливість її майбутнього перетворення.

Наприклад:

- звільнення заблокованої фігури;
- створення прохідного пішака;
- відкриття лінії;
- перехід до вигідного ендшпілю;
- перетворення позиційної переваги на тактичну;
- зміна функціональної ролі фігури.

`X(P) = g(reachable_structures, transformation_cost, future_options)`

Але тут є важливе обмеження.

Не можна оцінювати потенційну трансформацію так, ніби вона вже відбулася.

Її цінність залежить від можливості реалізації та відповідей суперника.

Тому X має бути пов'язаний із пошуковим алгоритмом.

# 5. Контекстуальна модель

## 5.1. Контекст як модифікатор

Використовуємо шахову прикладну модель:

`C(P) = I × Z × Φ`

де:

`I = {QUIET, DEFENCE, ATTACK, PRESSURE}`

`Z = {GLOBAL, QUEENSIDE, KING, CENTER}`

`Φ = {OPENING, MIDDLEGAME, ENDGAME, TRANSITION}`

Це 64 контекстні комбінації.

Вони не є заміною канонічної системи координат SUBIT ISA.

## 5.2. Контекстуальні інтенсивності

Для кожної характеристики визначимо:

`wᵢ(c,P) ∈ [0,1]`

Інтенсивності можуть перекриватися.

Наприклад, позиція може одночасно мати:

- високу атакувальну інтенсивність;
- високу захисну інтенсивність;
- значний контроль центру;
- ознаки переходу між фазами.

Не потрібно примусово вибирати лише один контекст.

## 5.3. Контекстуальна функція

`E_c(P) = Σᵢ wᵢ(c,P) · fᵢ(P)`

Загальна оцінка може враховувати кілька контекстів:

`E_context(P) = Σ_c α_c(P) · E_c(P)`

де α_c — параметри агрегування.

Потрібно встановити обмеження, щоб одна й та сама характеристика не враховувалася багаторазово через перекриття контекстів.

Можливе рішення — нормалізація контекстуальних коефіцієнтів або використання спільної моделі з контекстними взаємодіями.

Це окрема задача калібрування.

# 6. Повна структурна функція

Об'єднаємо сім вимірів:

`V(P) = (M, A, R, K, T, Q, X)`

Тоді базова скалярна оцінка:

`E₀(P;θ) = w_M·M + w_A·A + w_R·R + w_K·K + w_T·T + w_Q·Q + w_X·X`

Це лише базова лінійна модель.

Для SUBIT-CHESS доцільно досліджувати розширену форму:

`E(P;θ) = E₀(P;θ) + E_interaction(P;θ) + E_context(P;θ)`

де:

- E₀ — базові виміри;
- E_interaction — взаємодії характеристик;
- E_context — контекстуальні модифікації.

Взаємодії можуть бути представлені як:

`E_interaction = ΣᵢΣⱼ βᵢⱼ · fᵢ(P) · fⱼ(P)`

Наприклад, матеріальна перевага може мати різне практичне значення залежно від безпеки короля.

Але кількість взаємодій потрібно контролювати, інакше модель стане надмірно складною та схильною до перенавчання.

# 7. Нелінійна структурна оцінка

Лінійна модель не завжди достатня.

Деякі структурні характеристики мають пороговий характер.

Наприклад:

- відсутність захисту короля може бути критичною;
- одна відкрита лінія може мати невелике значення;
- декілька взаємопов'язаних відкритих ліній можуть створювати значну атаку.

Тому можна використовувати нелінійні функції:

`E_nonlinear(P) = Σᵢ wᵢ · hᵢ(fᵢ(P))`

де hᵢ — контрольована функція перетворення.

Можливі форми:

- лінійна;
- насичувальна;
- порогова;
- кусочно-лінійна;
- монотонна нелінійна.

Наприклад, насичувальна функція:

`h(x) = x / (1 + |x|)`

Вона обмежує надмірне зростання внеску однієї характеристики.

Вибір конкретних функцій повинен бути предметом контрольованої оптимізації.

# 8. Структурна цінність і часовий горизонт

Одна з найважливіших проблем шахової оцінки — відмінність між поточною цінністю та майбутньою реалізацією.

Позиція може бути структурно перспективною, але її перевага потребує багатьох ходів.

Тому визначимо:

`SVF(P,d;θ)`

де d — горизонт пошуку.

Для d=0:

`SVF(P,0;θ) = E(P;θ)`

Для d>0:

`V(P,d) = maxₘ [−V(T(P,m),d−1)]`

Це означає, що структурна функція оцінює листові позиції, а пошук враховує наслідки трансформацій.

Важливо не підміняти повноцінний пошук додаванням довільного прогнозу майбутнього.

Потенціал X має бути обґрунтований доступними легальними продовженнями.

# 9. Проблема подвійного обліку

Структурні характеристики можуть перетинатися.

Наприклад:

- контроль поля може збільшувати мобільність;
- захист фігури може збільшувати її функціональну цінність;
- координація може створювати тактичну загрозу;
- безпека короля залежить від кількості захисників.

Якщо всі ці характеристики незалежно додаються до оцінки, одна й та сама перевага може враховуватися кілька разів.

## 9.1. Формалізація

Нехай:

`f₁, f₂, ..., fₙ`

— характеристики позиції.

Якщо:

`Corr(fᵢ, fⱼ)`

є надмірно високою, потрібно перевірити, чи не описують вони одну структурну властивість.

## 9.2. Рішення

Потрібно:

1. Розділяти первинні факти та похідні характеристики.
2. Фіксувати походження кожної оцінки.
3. Визначати залежності між показниками.
4. Використовувати контрольовані взаємодії.
5. Проводити абляційні тести.
6. Перевіряти, чи зберігається внесок характеристики після вилучення іншої.

Необхідно пам'ятати: статистична кореляція не доводить семантичної тотожності.

Дві характеристики можуть бути пов'язаними, але описувати різні аспекти позиції.

# 10. Структурна оцінка ходу

Оцінка позиції повинна бути пов'язана з оцінкою трансформації.

Нехай:

`P' = T(P,m)`

Тоді:

`ΔΩ(P,m) = Ω(P') − Ω(P)`

Це узагальнене представлення структурних змін.

Його можна розкласти на:

`ΔΩ = (ΔF, ΔR, ΔA, ΔM, ΔK, ΔT, ΔQ, ΔX)`

де:

- ΔF — зміна складу фігур;
- ΔR — зміна відносин;
- ΔA — зміна активності;
- ΔM — матеріальна зміна;
- ΔK — зміна безпеки;
- ΔT — тактична зміна;
- ΔQ — просторова зміна;
- ΔX — зміна потенціалу.

## 10.1. Позитивні та негативні зміни

Не можна вважати, що кожна нова структурна властивість є покращенням.

Наприклад:

- нова атака може бути тактично неспроможною;
- збільшення мобільності може послабити короля;
- відкриття лінії може допомогти супернику;
- усунення блокування може звільнити ворожу фігуру.

Тому:

`ΔΩ ≠ ΔValue`

Зміна структури не тотожна зміні цінності.

## 10.2. Функція оцінки ходу

`MoveValue(P,m) = SVF(T(P,m)) − SVF(P)`

Ця різниця є діагностичною характеристикою.

Вона не замінює minimax, оскільки не враховує повністю найкращу відповідь суперника.

---

# 11. Контрфактична структурна оцінка

Для розуміння значущості елемента можна досліджувати, як змінилася б структура за його відсутності.

Нехай x — структурний елемент.

Визначимо:

`ΔF(x,P) = F(P) − F(P \ x)`

Це контрфактичний аналіз.

Він допомагає визначити:

- критичні фігури;
- ключові захисні відносини;
- залежності;
- структурні вузькі місця;
- елементи, від яких залежить функціонування позиції.

Але операція P \ x не обов'язково є легальним шаховим ходом.

Це аналітичне вилучення елемента для дослідження залежності.

Не можна плутати його з реальною трансформацією шахової позиції.

---

# 12. Невизначеність структурної оцінки

Оцінка позиції не завжди має однакову надійність.

Наприклад:

- матеріальний баланс може бути визначений точно;
- мобільність — обчислена точно в межах легальних ходів;
- стратегічна перспективність — евристична;
- довгостроковий потенціал — залежний від пошуку.

Тому необхідно зберігати не лише оцінку, але й рівень її обґрунтованості.

Визначимо:

`Confidence(P) = (c_M, c_A, c_R, c_K, c_T, c_Q, c_X)`

Це вектор характеристик надійності, а не обов'язково статистичні ймовірності.

Для кожного компонента потрібно фіксувати:

- джерело;
- метод отримання;
- точність;
- залежність від евристик;
- чутливість до горизонту пошуку.

Наприклад, точний факт легального шаху має інший статус, ніж припущення про майбутню позиційну перевагу.

## 12.1. Невизначеність і пошук

Можна досліджувати адаптивне збільшення бюджету пошуку для позицій із високою невизначеністю.

Але це має бути окремо перевірено експериментально.

Висока невизначеність не завжди означає, що додатковий пошук буде корисним.

---

# 13. Особливий статус термінальних позицій

Евристична функція не повинна визначати результат шахової партії там, де він точно встановлюється правилами.

Пріоритет:

1. Мат.
2. Пат.
3. Інші передбачені правилами завершення.
4. Легальні ходи.
5. Евристична оцінка.

Формально:

`Terminal(P) → TerminalValue(P)`

і лише якщо позиція не є термінальною:

`NonTerminal(P) → SVF(P)`

Точні правила мають пріоритет над структурною евристикою.

Окремо потрібно враховувати історично залежні правила завершення, включно з повторенням позиції та правилом 50 ходів, а також відповідні правила автоматичної нічиєї.

---

# 14. Калібрування параметрів

Функція SVF залежить від параметрів θ.

Їх не можна встановлювати лише інтуїтивно.

Потрібно використовувати:

- контрольовану самогру;
- внутрішні тактичні тести;
- незалежні контрольні набори;
- абляційний аналіз;
- локальну оптимізацію;
- еволюційну оптимізацію.

## 14.1. Калібрування

`θ* = arg maxθ J(θ)`

за умов:

`θ ∈ Θ_valid`

`Regression(θ) = PASS`

## 14.2. Захист

Не можна дозволяти оптимізатору змінювати:

- визначення легальних ходів;
- точні правила шахів;
- семантику відносин SRA;
- термінальні умови.

Оптимізуються лише параметри інтерпретації та пошуку.

# 18. Підсумкова концепція

SUBIT-CHESS STRUCTURAL VALUE FUNCTION вводить принципове розділення трьох рівнів:

**Перший рівень — ЩО Є?**

Структура позиції:

`Ω(P)`

**Другий рівень — ЯК ЦЕ ВЗАЄМОДІЄ?**

Відносини, контексти та трансформації:

`R(P), C(P), T(P), X(P)`

**Третій рівень — ЯКУ ЦІННІСТЬ ЦЕ МАЄ?**

Функція оцінювання:

`SVF(P,s;θ)`

Таким чином, шахова позиція перестає бути для двигуна лише набором зайнятих полів.

Вона стає структурою, у якій кожна фігура має функціональне положення, кожне відношення може змінювати значення інших елементів, а кожен хід створює нову конфігурацію можливостей та обмежень.

Це і є центральна ідея структурного підходу SUBIT-CHESS:

**Цінність позиції визначається не тільки тим, що в ній присутнє, а й тим, як присутні елементи організовані, взаємодіють і здатні трансформуватися.**
