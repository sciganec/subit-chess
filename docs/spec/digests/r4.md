## 37_SUBIT_CHESS_UNCERTAINTY_&_CONFIDENCE_THEORY_v1.0.md (1393 lines, fully read)

(1) Purpose: Formal epistemic layer (UCT) that separates evaluation, probability, confidence, uncertainty, stability and evidence for each analytic claim; defines calibration, stability, coverage and uncertainty-reduction procedures. Explicitly reporting/control-oriented; adds no new eval terms.

(2) Key definitions / invariants / test IDs:
- S2 P=(B,s,CR,EP,H,N,History); V(P,d,theta). S2: V=+0.75 is NOT 75% win probability / confidence / tree coverage / proof.
- S4 UCT(P)=(U,C,R,E,K,T,V,Pr); UCRecord=(ID,Claim,Type,Context,U,C,E,Status,Provenance).
- S5 eight uncertainty types: Us search, Ut tactical, Ue evaluation, Ur structural, Up strategic, Uh temporal, Um model, Uc contextual. S6 U(P)=(Us,Ut,Ue,Ur,Up,Uh,Um,Uc); each may be qualitative/number/interval; if Ui in [0,1] calibration method must be defined.
- S7: Confidence != 1 - Uncertainty (kept separate).
- S8 EvidenceStatus={UNVERIFIED,OBSERVED,COMPUTATION_DERIVED,TEST_SUPPORTED,SEARCH_SUPPORTED,FORCED_WITHIN_SCOPE,FORMALLY_PROVED,REFUTED,UNKNOWN,CONTEXT_DEPENDENT} (not a linear scale).
- S9 C(P,m)=(E,S,K,R,G) = evidence, stability, coverage of critical variations, model reliability, context validity (vector, not a probability).
- S10 Evaluation V vs Probability Pr(X) vs Confidence(Claim).
- S11.2 Brier: BS = (1/N) * sum_i (p_i - o_i)^2. S11.3 ECE = sum_b (|B_b|/N) * |acc(B_b) - conf(B_b)|. S11.4 calibrate per context class (open, closed, tactical, endgame, king attack, complex pawn structure).
- S12 DeltaV(d) = |V(P,d+1) - V(P,d)|; S12.1 PV(P,d)=(m1..mk), compare first move / initial moves / critical replies / leaf eval; S12.2 evaluation oscillation across depths -> flag (tactical instability, horizon effect, eval inaccuracy).
- S13 Coverage(P)=(L,T,R,H,X) = legal alternatives, tactical replies, defensive resources, horizon, critical continuations; descriptive only; depth alone is not completeness; selective search must not be reported as full minimax; quiescence reduces but does not remove horizon uncertainty.
- S14 KnowledgeBoundary=(Known,Derived,Supported,Hypothesized,Unknown,Refuted); Unknown != False.
- S15 plan profile Pi=(G,O,A,C,R,H,U), U(Pi)=(U_G,U_O,U_A,U_C,U_R,U_H); six plan checks (mechanism exists, opponent can block, alternative routes, time lost, tactical obstacle, plan still relevant).
- S16 ASSOCIATION / DEPENDENCY / CAUSATION distinction.
- S17 same C = I x Z x Phi 64 contexts as doc 30 S10 (identical sets).
- S19 qualitative levels L0 UNKNOWN, L1 WEAKLY SUPPORTED, L2 SUPPORTED, L3 STRONGLY SUPPORTED, plus FORMALLY VERIFIED.
- S21 D(P,m)=(V,Risk,U,C,E).
- S23 UCT-INV-001..020 (Evaluation/Confidence/Uncertainty/Stability Separation, Evidence Integrity, Search Scope, Context Preservation, No False Probability, Model Awareness, Unknown Preservation, Evidence Provenance, Calibration Independence, Contextual Calibration, No Double Counting, Temporal Validity, Tactical Priority, Bounded Claims, Reproducibility, No Automatic Uncertainty Penalty, No Consciousness Inference).
