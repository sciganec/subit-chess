## 18_SUBIT_CHESS_POSITION_SPACE_&_CONFIGURATION_TOPOLOGY_v1.0.md (1513 lines, fully read)
(1) Purpose: PSCT (Ukrainian-language, DRAFT theoretical spec) models chess as a transition system over a configuration space: reachability graph, structural/contextual distances, neighborhoods, trajectories, configuration memory. Explicitly a research programme ("no claim chess has a universal topology"); search stays the final arbiter of moves.
(2) Key definitions/invariants/IDs:
- S3.1 P=(B,s,C,E,H,N,history); S3.2 P_reachable ⊆ P_valid ⊆ P_encoded; S4 graph G=(V,E), labeled edges e=(P,m,Q), directed; Reach(P,d).
- S6 three distances: d_game (directed min legal moves, ∞ if unreachable), d_struct=D(Ω(P),Ω(Q)) with Ω=(F,R,A,D,M,K,T), d_context=D_c(C(P),C(Q)); S6.4 vector D_PSCT=(d_game,d_struct,d_context,d_material,d_tactical,d_dynamic), no scalar collapse.
- S7.2 δ_i=|f_i(P)-f_i(Q)|/r_i; S7.3 d_weighted=Σ w_i·δ_i (w_i≥0; pseudometric if some w=0). S8.1 P~εQ iff d_struct≤ε (not transitive). S9.3 structural neighborhood ≠ game neighborhood. S10 regions U_ε(P)={Q|d_struct<ε}.
- S11.1 Δ(P,m)=d_struct(P,T(P,m)); S11.3 critical if Δ>θ (no universal θ); S11.4 Mode(P)∈{QUIET,TENSION,TACTICAL,FORCED,TERMINAL}.
- S12.2 Δ_conn(x,P)=Conn(G(P))-Conn(G(P)\x) (counterfactual critical node; overloaded-defender detector, S12.4).
- S14.2 L_struct(γ)=Σ_t d_struct(P_t,P_t+1); S14.3 η_struct=d_struct(P0,Pn)/L_struct (not a strength measure). S15 attractors A_π only policy-dependent. S16.4 d_goal(P,Π)=inf{d_struct(P,Q)|Q∈T_Π}.
- S17.1 ConfigurationRecord=(ID,StateSignature,StructuralSignature,Context,Provenance,Version).
- Invariants S21 PSCT-INV-001..016 (notably 009 no value collapse, 012 analogy non-authority, 013 search completeness: configuration heuristics may not silently remove legal moves from full search, 014 train/validation separation, 015 no external teacher).
- Verification S22.1-22.5; experiments S23 PSCT-EXP-01..09 (05 Search Ordering, 06 Search Efficiency same budget, 08 Ablation, 09 paired colour-swapped self-play); plan S24 PSCT-01..16; acceptance S25 (10 criteria, incl. (3) CONCRETE implementable items affecting move choice/search: none with exact formulas/constants. Only qualitative suggestions, all unparameterised:
- S16.1-16.3: compute d_struct(P,P_m) per candidate and group candidates by transformation type (preserve/strengthen/break structure, material change, king-safety change, regime change) to inform MOVE ORDERING; S16.3 each candidate must keep its own search (no sharing of scores within a group). No ordering formula, no weights, no threshold (θ explicitly undefined, S11.3).
- S11.2/S11.4: Critical(P,m)/Mode change as possible trigger for extensions/budget allocation (H-PSCT-04); undefined criteria, listed inputs: material change, king-safety change, forced threats, loss of key defender, line opening, endgame-type change, terminal status.

## 22_SUBIT_CHESS_CAUSAL_ROBUSTNESS_&_STRATEGIC_RESILIENCE_THEORY_v1.0.md (1374 lines, fully read)
(1) Purpose: theory of plan robustness: whether a strategic plan's causal preconditions survive opponent counterplay and context change; plan fragility, redundant paths, recovery, adaptive replanning. Explicitly vector-valued, uncalibrated, and subordinate to minimax search.
(2) Key definitions/invariants/IDs:
- S1.3 five stability dimensions (structural, causal, strategic resilience, adaptive capacity, tactical robustness). S2.2 plan Π=(G,O,A,C,R,H,U); C_critical, C_alternative. S2.3 SR=(S_struct,S_causal,S_tactical,S_adaptive,S_recovery) "vector, not calibrated formula".
- S3.3 Fragility(Π)=ImpactLoss(Π)/PerturbationCost(Π) (only after scales made commensurable); FragilityProfile=(CriticalDependencies,FailureScenarios,Impact,RecoveryOptions,Confidence). S3.4 structural fragility vs tactical vulnerability vs strategic fragility (distinct).
- S4.3 independence grades INDEPENDENT/PARTIALLY_DEPENDENT/SHARED_CRITICAL_CONDITION/HIGHLY_DEPENDENT/UNKNOWN. S5.3 RobustValue(P,m,d)=min_{r∈B(P,m)} V(T(T(P,m),r),d-1); negamax V(P,d)=max_{m∈L(P)}[-V(T(P,m),d-1)]. S5.4 scenario types ADVERSE_SCENARIO/OPPONENT_OPTIMAL_RESPONSE/RANDOM_PERTURBATION/STRUCTURAL_COUNTERFACTUAL.
